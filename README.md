# HR-Analytics-Dashboard-Tableau
An interactive HR Analytics dashboard developed using Tableau to explore employee attrition, workforce demographics, job satisfaction, and department-wise HR metrics.
Dashboard includes:

Employee and active employee KPIs
Attrition count and attrition rate
Department-wise attrition
Attrition by gender
Age-group analysis
Education field-wise attrition
Job satisfaction by job role
Interactive visualizations for HR analysis

Tech Stack:
Tableau | Data Analytics | Data Visualization | HR Analytics
